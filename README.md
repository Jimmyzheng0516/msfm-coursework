# msfm-coursework

My own problem sets, study notebooks and class code from the University of Chicago **M.S. in Financial Mathematics** (September 2025 to June 2026; graduating December 2026). Only files I wrote are included; instructor solutions, lecture notebooks and exam papers are not.

| Folder | Course | Content |
|---|---|---|
| `FINM32000-numerical-methods/` | Numerical Methods (spring 2026) | Completed homework 1–7: analytic approximations and implied volatility, binomial/trinomial trees with time-dependent volatility, explicit and implicit finite differences and Crank–Nicolson for PDE pricing, Monte Carlo with variance reduction, Longstaff–Schwartz for American options, exponential Ornstein–Uhlenbeck forwards. `Study-Notes/` are the self-contained notebooks I wrote while preparing for the final, one per topic. |
| `FINM36700-portfolio-risk-management/` | Portfolio and Risk Management (autumn 2025) | `portfolio.py` (tangency and mean-variance weights, performance, drawdown and tail metrics, OLS factor metrics, penalized regressions with gross-exposure limits, correlation clustering and plots), a class exercise, and my exam-review notebook |
| `FINM33160-machine-learning-in-finance/` | Machine Learning in Finance (winter 2026) | Homework 1–3: decision trees, random forests and AdaBoost applied to return-sign prediction, with hyper-parameter search |
| `FINM34000-probability/` | Probability and Stochastic Processes (autumn 2025) | Problem set 5 |
| `STAT33910-financial-statistics/` | Financial Statistics (winter 2026) | Midterm take-home in R |

Larger course projects live in their own repositories: [`finm33200-genai-homework`](https://github.com/Jimmyzheng0516/finm33200-genai-homework), [`ML-Group-Project`](https://github.com/Jimmyzheng0516/ML-Group-Project), [`trend-following-regime-analysis`](https://github.com/Jimmyzheng0516/trend-following-regime-analysis) and [`commodity-multi-agent-trading`](https://github.com/Jimmyzheng0516/commodity-multi-agent-trading).

Files are committed on their last-modified date, so the history reflects when the work was done.
